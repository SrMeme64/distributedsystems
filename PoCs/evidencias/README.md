# Evidencias de las PoC

Aquí guarda las capturas de tus pruebas **cliente → host**. Los archivos de esta
carpeta no se versionan: `.gitignore` excluye todo excepto este README, así que
puedes pegar salidas, CSV o capturas de pantalla sin ensuciar el repositorio.

Sugerencia de nombres:

- `poc1-carga-fria-caliente-<fecha>.txt`
- `poc2-failover-cliente-<fecha>.txt`
- `poc2-failover-host-<fecha>.txt`
- `poc3-chaos-cliente-<fecha>.txt`
- `poc3-chaos-host-<fecha>.txt`

Cada PoC del [`README.md`](../README.md) documenta sus resultados en la sección
**Resultados obtenidos**. Los de la ejecución del 26-10-2026 están resumidos en
el [`README.md`](../README.md#resultados-principales).
